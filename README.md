One satirical sentence, written by `main.ts` to `/output/entry.txt`, roasting
lawmakers who regulate AI, crypto or the internet but cannot convert a file
to PDF.

> The congressman who wrote the 40-page AI Accountability Act printed it out, signed it in pen, and had his intern fax it to the PDF department.

## How it works

`main.ts` (Node 22+, standard library only, deterministic) writes the single
sentence above to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No input data, no network,
no dependencies — the same text on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
